Sudo MDM App派送

應用程式類別​

類別說明
VPP應用程式在ASM購買大量授權的程式
APP應用程式在Apple Store購買的應用程式，需要登入Apple ID
AdHoc應用程式沒有公開上架的應用程式

應用程式可用證確認​

Tip:可用證數量即ASM購買許可的數量

操作流程

程式與電子書→應用程式→應用程式管理

Tip:若ASM購買後成功派送可在應用程式內看到該App，可透過搜尋或下拉頁面找到APP

Tip:後方可看到可用證資訊(已使用/可用証數量)以及載具資訊(已安裝/未安裝/需要更新)

VPP應用程式可用證確認​

操作流程

程式與電子書→VPP→VPP設定→查看VPP可用證使用狀況 (已使用/安裝數)


若未看到該App可進行更新VPP應用程式​

操作流程

程式與電子書→VPP→VPP設定→更新VPP應用程式→同步VPP應用程式

Your Turn

自我檢測:​

嘗試查看應用程式是否有派送成功至SudoMDM

應用程式管理/ VPP應用程式/ 同步VPP應用程式

VPP應用程式安裝​

方法一: 透過載具管理介面(可單機或批量安裝)​

操作流程

載具管理(亦可從首頁進入)→批量操作...→應用程式→安裝VPP應用程式→勾選要安裝的載具→勾選要安裝的應用程式→確定

方法二: 透過VPP應用程式介面(單一或批量VPP應用程式安裝)​

操作流程

程式與電子書→VPP→VPP應用程式→批量連繫

操作流程

載具勾選(單選或全選)

操作流程

應用程式勾選→確定

確認是否安裝成功​

操作流程

點選有上線的ipad

操作流程

VPP應用程式

1. 已安裝完成者會有綠色✔️

2. 未完成安裝者會出現紅色❌以及Vpp install

3. 點擊→VPP install

Tip:SudoMDM指令派送有時會有時間差，網頁更新可能未及時或是因為載具未上線，可直接確認載具是否已收到安裝指令並已進行安裝。(單機載具頁面/最新指令)

應用程式管理(多台確認是否安裝)​

操作流程

**方法一: 程式與電子書→應用程式→應用程式管理→缺少的應用程式→...→VPP安裝全部→確認



操作流程

方法二: 程式與電子書→應用程式→應用程式管理→找到該應用程式資訊(最右邊)→點未安裝(中間?方框)→...操作→VPP安裝全部→確認




Tip:若各項安裝程序已派送，仍未看到App已安裝，可嘗試"更新資料"或是”重新整理網頁

VPP應用程式/ 批量安裝/ 檢查是否安裝成功

解除安裝​

操作流程

載具管理→...操作(單機或批量操作)→應用程式→移除應用程式→選擇要移除的應用程式→確定

操作流程

批量操作→選擇載具→選擇應用程式→確定

操作流程

單機操作→選擇要移除的應用程式→確認

VPP應用程式更新​

查看VPP應用程式是否可更新​

操作流程

程式與電子書→應用程式→應用程式管理

操作流程

應用程式更新→查看APP版本

App後方資訊若有綠色✅表示可以更新，紅色❌表示目前無新版本

VPP應用程式更新​

1️⃣批量或全部更新

操作流程

操作→VPP安裝全部(此處會直接安裝全部的載具/批量安裝)→Confirm(確認)


2️⃣指定載具/批量或全部更新

操作流程

右上搜尋→APP名稱→點擊欲搜尋的APP→確認可更新


操作流程

VPP安裝→APP名稱→點擊欲搜尋的APP→確認可更新

操作流程

選擇載具(可單選或批量)→確定→再次確認

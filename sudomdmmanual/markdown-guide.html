Docusaurus 常用排版語法

這篇文件展示了如何使用 Markdown 寫出像 GitHub 文件那樣精美的排版。

1. 數字清單與行內程式碼​

您可以使用一般的數字加上句號來建立清單，並用反引號 ` 標示按鍵或檔名。如果想讓按鍵看起來更有立體感，可以使用 HTML 的 <kbd> 標籤！

  1. 點擊右上角的 Save 按鈕。
  2. 開啟您的終端機，輸入 npm start 啟動伺服器。
  3. 按下鍵盤上的 Enter (回車鍵) 繼續。
  4. 找到 index.html 右鍵點擊檔案。

2. 列表中的「內縮」與「程式碼區塊」​

如果您希望在數字「3」底下放一段程式碼，而且要對齊數字，關鍵在於程式碼區塊前面要加上 4 個半形空白或 1 個 Tab 進行內縮。

  1. 輸入以下提示並按下 Enter 鍵。代理程式將分析您的請求：

    迅速的
    Create a complete task manager web application...

    觀察代理程式如何產生實現您的請求所需的必要文件。我們來建立一個 styles.css 文件。

  2. 只要有空 4 個空白，原本的數字清單就不會被打斷！

3. 提示區塊 (Admonitions)​

截圖中那個左邊有黃色線條的「提示」區塊，在 Docusaurus 中叫做 Admonitions。只需要用 ::: 包起來即可。Docusaurus 預設提供五種顏色：

提示

不同的語言模式各有優勢。您可以使用聊天視圖中的模型選擇器來切換。

補充說明

這是一個藍色的資訊區塊，適合放一些額外的參考資訊。

注意事項

這是一個黃色的警告區塊，適合用來提醒使用者不要做錯步驟。

警告

這是一個紅色的危險區塊，用來標示會導致嚴重錯誤的操作！

4. 摺疊詳細資訊 (Details)​

如果有些補充說明太長，不想佔用太多版面，可以使用摺疊面板，使用者點擊才會展開：

點我展開：查看進階設定說明

這裡可以放進階的設定說明，甚至可以在裡面放程式碼：

npm run build

5. 強調文字區塊 (Blockquotes)​

如果您想引用一段話，或是做簡單的內縮強調，可以在文字最前面加上 > 符號：

💡 這是一段引用文字 Docusaurus 讓我們可以專注在撰寫內容，而不需要擔心網頁排版。
